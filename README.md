## Projetos e aprendizados

### [Jump Mario](https://github.com/Juzzo7/jump-mario)

Jogo simples de desviar de um cano, com salto acionado pelo teclado, animações em CSS e detecção de colisão em JavaScript. Um exercício de lógica, temporização e interação entre o código e os elementos da página.

**Tecnologias:** HTML, CSS e JavaScript.

### [Projeto Pokes](https://github.com/Juzzo7/projeto-pokes)

Página com cartões de Pokémon, imagens animadas, tipos e descrições. Inclui alternância entre os temas claro e escuro, praticando eventos, manipulação de classes e organização visual do conteúdo.

**Tecnologias:** HTML, CSS e JavaScript.

### [X-Men](https://github.com/Juzzo7/X-men)

Interface de seleção de personagens que atualiza imagem, nome e descrição ao passar o mouse sobre os cartões. O projeto reúne manipulação do DOM, atributos de dados e regras de CSS para adaptação do layout a telas menores.

**Tecnologias:** HTML, CSS e JavaScript.

### [Landing Page de arquitetura](https://github.com/Juzzo7/Landing-Page)

Página de apresentação de serviços de arquitetura, com seções informativas e formulário de nome e e-mail configurado para envio ao SheetMonkey. Um exercício de estruturação de conteúdo, estilização e integração de formulário com um serviço externo.

**Tecnologias:** HTML e CSS.  
[Site indicado no README do projeto](https://landingpagesolo.netlify.app)

### [Boot Camp DNC](https://github.com/Juzzo7/Boot-camp-dnc)

Exercício inicial de interface com barra de navegação e botão visual de login. O código atual concentra-se na estrutura e na estilização desses elementos.

**Tecnologias:** HTML e CSS.
